## 模組一：燈光開關

### 可用的材質

| 車身 | 大燈 | 方向燈 | 尾燈 |
|---|---|---|---|
| E36 五種 | `clearglass.0xx` | `orangeglass.0xx` | `redglass.0xx` |
| Eclipse | `Headlight_Bucket` / `Headlight_Inner` | （併在 Bucket） | `Taillight_Red` |
| M3 | `HeadLamp_lens` | `SideLamp_lens` | `RearLamp_lens` |

材質名的尾碼每個車身不同（`.032` / `.033` …），比對時用 `startsWith` 或去掉尾碼。

### 實作要點

- 在 `build` 加 `lights:{head:0, park:false, brake:false, turn:'none'}`
  （`head`: 0=關 / 1=小燈 / 2=近燈 / 3=遠燈）
- `styleImportedCar()` 裡對上表的材質設 `emissive` 與 `emissiveIntensity`
  - 大燈開：`emissive = 0xfff4e0`，intensity 近燈 1.2 / 遠燈 2.4
  - 尾燈：小燈 0.5、煞車 2.0，`emissive = 0xff1a1a`
  - 方向燈：`emissive = 0xff9500`，用 `setInterval` 每 400 ms 切換 intensity 0 ↔ 2.0
- 加「夜間模式」：把 `HemisphereLight` 強度從 2.2 降到 0.25、背景換深色，
  否則白天環境光太強，燈亮不亮看不出來
- 更新走 `updateCar3DBuild()`，不要整個 rebuild（改材質不需要重建幾何）

## 模組二：車輛移動

### 實作要點

- 狀態：`{x, z, heading, speed, steer, wheelSpin}`，放在 `CAR3D_INSTANCES` 的 instance 上
- 每幀（`renderer.setAnimationLoop`）更新：
  - `speed` 依油門/煞車加減，加空氣阻力
  - 自行車模型轉向：`heading += speed * tan(steer) / wheelbase * dt`
  - `car.position.x/z` 依 heading 前進，`car.rotation.y = heading`
  - 輪子自轉：`wheel.rotation.x += speed*dt / tireR`（注意輪組群組已有 camber/toe 的
    `rotation.order='YXZ'`，自轉要疊在既有旋轉上，不要直接覆寫）
  - 前輪轉向：在既有 toe 角上加 `steer`
- 操作：畫面上的方向鍵 + 鍵盤 WASD / 方向鍵。行動裝置用觸控搖桿
- 相機：加一個「跟隨」模式，`controls.target` 追車身位置；預設仍是自由 orbit
- 地面格線 `GridHelper` 要跟著平移（或做得夠大），否則車開出格線外會很怪
- 加「回到原點」按鈕

### 注意

- `OrbitControls` 與跟隨模式會打架，切換時要 `controls.enabled = false/true`
- 車身有 `applyBodyTilt()` 設的四元數，**車身朝向請改 `root` 群組的 `rotation.y`**，
  不要動 model 本身的 quaternion，否則會跟俯仰互相干擾

## 模組三：引擎聲音（Web Audio API 合成）

### 為什麼不用錄音

引擎錄音有著作權，逐一查授權成本高（本專案已在授權上反覆卡關）；
且 app 為單檔離線，音檔只能 base64 內嵌，會把 `index.html` 撐大好幾 MB。
合成零授權風險、零檔案大小，而且能跟轉速**即時連動** —— 吹油時聲音跟著上下，
這是播放固定音檔做不到的。

### 聲學基礎

- 點火頻率 `f = rpm / 60 × (cylinders / 2)`
  - 4G63T 四缸 @ 3000 rpm → 100 Hz
  - M52 直六 @ 3000 rpm → 150 Hz（所以直六天生比較滑順）
- 引擎資料已在 `MODELS` / `ENGINES` 裡，取缸數與紅線轉速當參數

### 訊號鏈

```
OscillatorNode(sawtooth) @ f          ← 基頻
  + 諧波 ×2 ×3 ×4（振幅遞減 0.6/0.35/0.2）
  + BufferSource(白噪音) 過 BandPass   ← 進氣／排氣氣流
→ BiquadFilter(lowpass, cutoff 隨負載開)
→ WaveShaper(輕微失真，負載大時加重)
→ GainNode(總音量)
→ destination
```

- 渦輪車另外加：**洩壓閥** —— 放開油門時觸發一段 0.25 s 的高頻噪音掃頻
- 排氣尾段選項（`build.tips`）可以微調 lowpass cutoff：四出比單出開得更亮

### 互動

- **必須有「發動引擎」按鈕** —— 瀏覽器規定要有使用者手勢才能開 AudioContext
- 發動：怠速 rpm 從 0 掃到 800、疊一段起動馬達的低頻脈衝
- 油門（按住或滑桿）：rpm 上升，放開回落到怠速，到紅線加限轉跳動
- 音量滑桿 + 靜音鍵，狀態存 localStorage
- 離開頁面 / 切分頁要 `suspend()`，不然背景會一直發聲

## 為什麼不做開門

七顆網格的車門、引擎蓋、後廂**全部與車身合併**：

| 網格 | 結構 |
|---|---|
| E36 五種 | 1 個 mesh、17–20 個材質 primitive，無任何 door / hood / trunk 節點 |
| Eclipse | 59 個 mesh，但依**材質**切（`GSX:M_CarPaint_Max` = 所有烤漆件），非依零件 |
| M3 | 整台車在一個 `Body_Plane` 群組 |

要開門必須：門是獨立物件 + 有鉸鏈軸心 + **有門內板與門檻內側的幾何**。
最後這項是關鍵 —— 這些模型都沒有內側面，硬把門切出來一打開就會看穿進車內，
就是先前修掉的那種黑洞破面。

兩條路：
1. 換一顆分件的模型（Sketchfab 搜 "separated parts" / "rigged"），但要重做一輪硬點量測
2. 不做

**不建議為了開門去切現有網格**，會把剛修好的畫質再弄壞一次。

## 建議順序

1. 燈光（最小、獨立、立刻看得到效果）
2. 聲音（與燈光無關，可平行）
3. 移動（最大，且會動到相機與地面，最後做）
