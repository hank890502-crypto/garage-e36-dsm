# Garage — E36 / DSM

一個單檔離線的車輛管理平台，支援 **BMW E36（1990–2000）** 與 **Mitsubishi Eclipse 2G / DSM（1995–1999）** 兩個平台。

打開就能用，不需要伺服器、不需要帳號、不需要網路。所有資料存在瀏覽器本機。

**線上版：** https://USERNAME.github.io/REPO/

## 功能

**改裝設計預覽** — 即時預覽車色、輪圈、車身高度、卡鉗顏色、隔熱紙與空力套件。輪圈相容性會依你的年份、引擎與車身型式做四級判斷，並計算輪胎外徑變化與外緣位移是否超出台灣法規門檻。

**原廠維修資料** — 兩個平台各自對應自己的原廠手冊。E36 有卡爾世達繁中手冊的保養規格表，Eclipse 有 4G63T 的完整規格與三段中文化的維修程序（正時皮帶、渦輪增壓測試、平衡軸）。

**保養提醒** — 以「剩餘量」進度條呈現：滿格代表剛做完，見底代表該換了。里程與時間分開推算，哪個先到就以哪個為準。逾期會告訴你超過多少。

**中油油價** — 內建牌價快照，可線上更新或手動輸入，並依你的車換算加滿一次要多少錢。

**圈速計時** — GPS 自動過線計時（過線時間在兩筆定位之間內插）或手動按圈。支援繞圈與分段路線（起點 → 中間點 → 終點），中間點會顯示與最佳一趟的 +/- 差距。每個場次會記錄當下的改裝狀態，之後可以直接比較改裝前後的圈速差異。

**故障診斷** — 症狀、故障碼、已知弱點、OBD 判別。E36 有 OBD 世代的判別說明，Eclipse 有 42 個原廠故障碼與 DSM 社群的已知弱點（crank walk 等）。

## 使用

直接下載 `index.html` 用瀏覽器打開即可。

有些功能需要 https 或本機伺服器才能運作：

- **GPS 圈速計時** 需要安全來源，用 file:// 開啟拿不到定位權限
- **中油油價線上更新** 在 file:// 下會被瀏覽器的跨網域限制擋掉

用線上版（GitHub Pages）或本機伺服器開啟就沒這個問題：

```bash
python3 -m http.server 8000
# 然後打開 http://localhost:8000
```

## 開發

原始碼在 `src/`，依檔名前綴分層，用 `build.sh` 串成單一 HTML：

```
01-02  HTML 骨架與 CSS
05     AI 生成素材（內嵌 base64 WebP）
10-19  資料層（車輛、輪圈、維修、零件、手冊、故障、油價、賽道、Eclipse）
20-21  狀態儲存與計算引擎
30-38  UI 與各頁面
90     啟動
```

```bash
./build.sh    # 產生 index.html
```

改資料只要動 `src/1*.js`，改畫面動 `src/3*.js`，不會互相影響。

## 資料可信度

每一筆規格都標了來源與可信度等級：原廠手冊 / 原廠文件 / 專業零件商 / 社群彙整 / 尚未驗證。
來源互相衝突時會兩邊都列出來並說明差異，不會擅自選一個當定論。

例如 Eclipse 的正時皮帶更換週期，手冊自己就有兩種說法（保養表 60,000 英里、規格頁 100,000 英里），
app 裡兩個都會顯示，並說明為什麼建議取短的。
