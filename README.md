# Garage — E36 / DSM

一個單檔離線的車輛管理平台，支援 **BMW E36（1990–2000）** 與 **Mitsubishi Eclipse 2G / DSM（1995–1999）** 兩個平台。

打開就能用，不需要伺服器、不需要帳號、不需要網路。所有資料存在瀏覽器本機。

**線上版：** https://hank890502-crypto.github.io/garage-e36-dsm/

## 功能

**改裝設計預覽** — 即時預覽車色、輪圈、車身高度、卡鉗顏色、隔熱紙與空力套件。輪圈相容性會依你的年份、引擎與車身型式做四級判斷，並計算輪胎外徑變化與外緣位移是否超出台灣法規門檻。

**駕駛場景** — 進入駕駛模式會換成一條依台灣法規標線畫出來的雙向四線道：車道線白虛線 4 m／間距 6 m、分向限制線雙黃實線、路面邊線白實線 15 cm（依「道路交通標誌標線號誌設置規則」第 182、165、183 條）。道路無限延伸、路肩有反光導標與路燈、遠方有丘陵與漸層天空。夜間模式下大燈會真的照亮路面、導標會反光。整個場景是程式生成的，沒有外部模型、沒有授權問題，也不會因為開太遠而穿幫。

**練車場地** — 駕駛模式可切換三種場地。**直線加速道**有起跑線與距離標記，停在線上一動就自動計時，量 0–60／0–100／0–200 km/h 與 60 ft／1/8 哩／1/4 哩的秒數加終點速度，並記錄最佳成績 —— 改完齒比或終傳可以直接跑一趟看差多少。**甩尾場**是一片有定圓標線與三角錐的柏油場地，會即時算滑移角、連續時間與分數。（甩尾要先關掉循跡防滑，排一檔、滿舵配油門沿定圓轉 —— 原廠扭力在二檔以上是破不了後輪的，這點跟真車一樣。）

**互動預覽** — 3D 預覽可以開燈（小燈／近燈／遠燈、煞車燈、雙黃警示、夜間模式），也可以直接把車開起來：WASD 或方向鍵駕駛、Q／E 換檔、空白鍵手煞車、左 Shift 踩離合，手機則用觸控搖桿、踏板與撥片。有手排與自排、跟隨鏡頭與循跡防滑開關。

**傳動改裝與車輛動力學** — 變速箱齒比（可逐檔自訂）、終傳比、LSD 差速器、離合器與飛輪都能換，而且是真的會影響開起來的樣子。底層是一套三自由度車輛模型：曲軸角度積分的引擎、有滑差的離合器、簡化 Pacejka 輪胎（含滑移率、滑移角、摩擦圓與胎體鬆弛長度）、前後與左右荷重轉移，以及依廠商定義實作的 LSD 扭力分配。關掉循跡防滑就能用油門和手煞車把車尾送出去，飄移角會即時顯示。

**引擎聲** — 不是播錄音，是即時合成的，而且 22 具引擎各有各的聲音。曲軸角度驅動每個汽缸的點火脈衝，依點火順序排列後送進排氣管的波導共鳴模型，再加上進氣噪音、機械噪音與渦輪嘯叫。所以直四和直六天生就不一樣、排氣尾段選四出會比單出開闊、斷油限轉會有噠噠聲、渦輪車放油門有洩壓閥。零音檔、零授權風險，聲音跟著轉速、負載與增壓即時變化。

每具引擎的差異是依實際物理建模的：SOHC 八汽門的 M40／M43 排氣洩放慢所以悶，DOHC 的 M42／M44 脈衝銳利；直六每轉點火三次、餘波未散下一缸就接上，這是那種滑順感的來源；歐規 M3 的 S50B30／S50B32 用獨立節流閥（每缸一個，直接對著進氣門），高轉的進氣嘶吼就是它，北美的 S52B32 是單一節流閥所以聽起來接近排氣量放大的 M52；柴油以燃燒敲擊為主角。實測 5500 rpm 下 S50B32 的頻譜亮度是四缸柴油 M41D17 的近十倍。

換檔、洩壓閥、回火這類「一次性事件」則可以用真實錄音取代合成 —— 把音檔放進 `assets/audio/` 就會自動接管，沒有檔案就用合成，兩邊都不會壞。要錄什麼、怎麼錄、格式規範見 [docs/音效製作規格.md](docs/音效製作規格.md)。

**原廠維修資料** — 兩個平台各自對應自己的原廠手冊。E36 有卡爾世達繁中手冊的保養規格表，Eclipse 有 4G63T 的完整規格與三段中文化的維修程序（正時皮帶、渦輪增壓測試、平衡軸）。

**保養提醒** — 以「剩餘量」進度條呈現：滿格代表剛做完，見底代表該換了。里程與時間分開推算，哪個先到就以哪個為準。逾期會告訴你超過多少。

**油耗紀錄** — 首頁可直接新增每次加油的里程、公升數與金額，以滿油到滿油的方式計算 km/L 與 L/100 km，中間的少量補油也會一併納入。

**中油油價** — 內建牌價快照，可線上更新或手動輸入，並依你的車換算加滿一次要多少錢。

**圈速計時** — GPS 自動過線計時（過線時間在兩筆定位之間內插）或手動按圈。支援繞圈與分段路線（起點 → 中間點 → 終點），中間點會顯示與最佳一趟的 +/- 差距。每個場次會記錄當下的改裝狀態，之後可以直接比較改裝前後的圈速差異。

**故障診斷** — 症狀、故障碼、已知弱點、OBD 判別。E36 有 OBD 世代的判別說明，Eclipse 有 42 個原廠故障碼與 DSM 社群的已知弱點（crank walk 等）。

## 使用

直接下載 `index.html` 用瀏覽器打開即可。

有些功能需要 https 或本機伺服器才能運作：

- **GPS 圈速計時** 需要安全來源，用 file:// 開啟拿不到定位權限
- **中油油價線上更新** 在 file:// 下會被瀏覽器的跨網域限制擋掉

用線上版（GitHub Pages）或本機伺服器開啟就沒這個問題：

```bash
python3 -m http.server 8000
# 然後打開 http://localhost:8000
```

## 開發

原始碼在 `src/`，依檔名前綴分層，用 `build.sh` 串成單一 HTML：

```
01-02  HTML 骨架與 CSS
05     AI 生成素材（內嵌 base64 WebP）
10-19  資料層（車輛、輪圈、維修、零件、手冊、故障、油價、賽道、Eclipse）
20-21  狀態儲存與計算引擎
30-38  UI 與各頁面
90     啟動
```

```bash
./build.sh    # 產生 index.html
```

改資料只要動 `src/1*.js`，改畫面動 `src/3*.js`，不會互相影響。

## 資料可信度

每一筆規格都標了來源與可信度等級：原廠手冊 / 原廠文件 / 專業零件商 / 社群彙整 / 尚未驗證。
來源互相衝突時會兩邊都列出來並說明差異，不會擅自選一個當定論。

例如 Eclipse 的正時皮帶更換週期，手冊自己就有兩種說法（保養表 60,000 英里、規格頁 100,000 英里），
app 裡兩個都會顯示，並說明為什麼建議取短的。
